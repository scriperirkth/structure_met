# Структуры метаданных 1С

Репозиторий хранит исходные описания метаданных конфигураций и производные представления для исследования через GitHub Connector. Конфигурации, версии и имена файлов могут меняться.

## Текущее размещение

На момент подготовки документации, 23 октября 2026 года, корневое дерево содержит:

- `УППСТР.xml` — исходный файл; конфигурацию и версию подтверждать по содержимому.
- `readable/` — части исходника; вход: [индекс](readable/index.md).
- `split_xml.py` — существующий скрипт разбиения.
- `Как делить.txt` — прежний пример команды; не считать универсальной инструкцией.

При смене источника обновите этот раздел. Имена файлов не доказывают конфигурацию, версию или актуальность.

## Предпочтительная объектная навигация

Проектный вход: `object_readable/index.md`. На момент проверки корня этот каталог и `build_structure_navigation.py` не обнаружены. Обсуждение генератора не равно его публикации или успешному запуску.

После публикации сначала прочитайте общий индекс и существенные сведения `manifest.json`. Маршрут: индекс → раздел имён → объект → связанные свойства → типы. Фактические пути берите из ссылок.

XML отдельной записи не обязательно содержит все свойства объекта. Связанные записи не доказывают полноту бизнес-набора, например всех сведений о физлице. При необходимости отдельно исследуйте самостоятельные регистры и объекты, ссылающиеся на него.

## Резервное чтение

`readable` — не каталог самостоятельных объектов. При байтовом разбиении граница может проходить внутри XML, значения и обработчика. Получайте начало и конец элемента, при необходимости читайте соседние части без добавления символов на границах. Обрезанный ответ инструмента не является полным файлом.

## Обновление

См. [UPDATE_GUIDE.md](UPDATE_GUIDE.md). Не смешивайте старые и новые части. После изменения источника актуальность производной навигации проверяется заново. Для нескольких конфигураций используйте отдельные источники и выходные каталоги, явно перечисленные ниже.

## Карта источников

| Источник | Читаемое представление | Статус |
|---|---|---|
| `УППСТР.xml` | `readable/index.md` | Существующий маршрут; соответствие снимку проверять по хешам |
| Выбранный источник генератора | `object_readable/index.md` | Проектный маршрут; публикация и чтение ещё не подтверждены |

При добавлении конфигурации замените проектную строку конкретной записью: конфигурация, версия, исходник, SHA-256, индекс, статус проверки.

## Границы доказательности

Метаданные подтверждают структуру и типы, но не поведение отсутствующего BSL. Индекс подтверждает навигацию, но не заменяет XML. `BUILT` не означает проверку в 1С. Локальный путь не передаёт файлы ИИ.

Запуск генераторов и публикация требуют отдельного решения пользователя. Исходники не изменять ради навигации; секреты и персональные данные не публиковать.
